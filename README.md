# Expense Tracker API

A RESTful expense management API built with **FastAPI** and **PostgreSQL**.

## Features

- User registration and login
- JWT-based authentication
- Protected routes with user authorization
- Create, read, update, and delete expenses
- Expense categories
- Expense filtering, pagination, and sorting
- Spending summaries and reports
- Automated API testing with Pytest
- PostgreSQL database
- Deployed on Render
